# 单微电网执行证据

专用页顶部按专利二页面的状态结构展示：未选择任务或结果时隐藏运行摘要；有任务但无完整结果时显示已完成周期及停止说明；完整结果显示来源、生成时间和分项概览。当前回放周期位于播放器中，与实际已完成周期分开，不因手动回看而减少执行进度。五个视图始终可访问，任务停止后保留已收到的周期记录。

负责人：前端维护负责人；复核：仿真研究维护负责人。公开入口 `index.ts`。

读取生成的 SingleExecution 契约与服务端经济性结论，分别展示目标接纳/拒绝、安全、周期末跟踪、计划经济性和研究假设。
保留原请求与接纳值、绝对期限和有限保证终点，接纳前调整的内部目标不伪装成原请求。
原目标反馈续接和经济规划失败分别展示，续接认证不计作经济求解成功。
该组件不重新求解、认证或裁定安全。依据 ADR 0046、0049；历史结果通过归档环境读取。

`case-page.tsx` 是单微网路由的 8.2 专用入口，固定 SC、全天 8 个参考时段、启用储能和无事件；任务恢复时验证结果属于该实施例。页面提供运行、取消、真实任务进度和执行过程回放。`SingleExecutionDemo` 的专用模式只显示执行证据；设备 P/Q、PCC 跟踪、电量任务、滚动规划及网络证据共用已完成周期。旧结果缺少逐周期网络证据时显示未记录。新结果保存后台已完成的 `cycle_evidence`，独立复核会重新计算并比较这些数据。

首页和单微网路由均使用此页面。上方“保存记录”与专利二共用 `SavedRecordSelector`：用户选择已有示范计算，或点击“现场重新计算”。普通进入页面只读取示例列表和固定条件，不自动加载临时任务或启动求解。`?simulation=library:core` 恢复保存示例，明确的任务编号仍走既有任务恢复流程。加载记录或计算期间禁止切换记录；重新计算保留实时进度、取消及执行反馈，旧结果不与新任务混用。

`GET /api/single-example/library` 列出长期示例，`GET /api/single-example/library/core` 读取 `results/single_examples/core.json`，独立于临时任务保留策略。后端校验当前结果契约、固定请求、完整 1440 周期、网络/设备/预测/研究参数、初态及数据集；历史上下文摘要原样保留，输入逐字段比较。界面显示真实生成时间与原始评估结论。现场新任务不会覆盖长期示例。

维护时可运行 `python tools/prepare_single_library.py --result <完整结果.json>` 原样导入已有兼容记录，或不传 `--result` 计算全天示例。覆盖已有库记录必须显式传 `--replace`。当前示例来自 2026-11-01 的真实完整计算，导入保留原文件字节及生成时间；部署时需一并保留 `results/single_examples/`。校验可设置 `SINGLE_DEMO_ARCHIVE` 指向真实记录后运行 `tests/integration/service/test_single_library.py` 及前端组件测试。

`live.tsx` 把计算中事件和完成后的 `UnifiedExecution` 转换为同一展示模型，使用同一组设备卡片、图表和网络拓扑。计算中默认跟随最新已完成周期；也可定位已完成周期；完成后保留相同视图、周期定位和轨迹播放。任务编号不变时，切换到最终记录不重置已选周期。风机、光伏、储能、SVG 和网络活动动画在执行或回放时运行。

专用页与专利二实施例共用局部浅色科研主题。共同条件、规划决策、执行监控、专项任务和证据与结论通过五个分项切换，始终共享时间位置；切换分项不重新计算或重置资源选择。网络活动使用无方向的轻微明暗变化，不表达实际潮流方向；设备动画不表示实际转速，且遵从系统减少动态效果设置。主题不改变其他业务页面的样式。

完整结果的计划、证书和逐周期详细表格在主视图内按需展开，共用主视图的周期；窗口与表格定位也会更新主周期。设备资源选择及其命令曲线、储能任务范围、分开的 PCC P/Q 外包与误差带均在主图中展示，不重复绘制。旧实时记录可能不包含误差带参数，页面不推测数值；新运行按后台声明的误差带展示。实时增量未包含完整规划见证、原始观测和网络证书时，详细区说明须待最终结果，不能补造证据。`SingleExecutionDemo` 的独立模式仍供其他业务页面使用。重新运行时，旧结果不与新任务合并，页面提供原任务链接。沿用项目现有 React/SVG 图表，无新增运行依赖。

后台在周期提交后发布轻量记录，工作进程将记录原子写入任务目录的 `attempts/<attempt_id>/live/<stream>/`。协调进程根据任务 `execution.json` 中的当前 `attempt_id` 读取记录；没有执行清单的历史任务兼容直接写入任务根目录的记录。`GET /api/simulations/{id}/live?after=N&stream=...` 每次最多返回 32 项，返回 `cursor` 与 `more`；前端每 400 ms 补取新数据，有积压时连续补取。任务阶段继续使用现有 WebSocket。不同工作尝试使用不同 stream，序号重新开始；刷新后可从头恢复，临时断线按已收到的序号续取。文件随既有任务保留策略清理。

实时数据仅包含已经完成的周期。参考求解阶段尚无执行记录，页面显示当前计算阶段。失败或取消后保留已收到的数据并停止活动动画；最终结果发布后切换到完整结果及回放。实时区间中点与后台外包区间区分显示，不替代后台安全认证。历史任务未保存实时记录时，继续通过最终结果回放。


`GET /api/single-example/inputs` 在不启动求解的情况下描述固定算例。`prepare_unified_single` 同时服务正式执行和条件介绍，避免另一套展示参数；接口含执行域、初态及参考计划时间轴。新实时初态记录也附带执行域与滚动间隔。展示优先采用当前完整结果或当前任务的记录；历史结果缺少条件时明确说明，不使用当前预览补造历史输入。

“规划决策”复用滚动规划与接纳证据；“执行监控”集中展示原有设备、PCC、网络；“专项任务”展示原期限电量曲线及任务证据；“证据与结论”分别说明条件安全、目标接纳、期限后跟踪、原期限任务和计划经济性。规划完整见证尚未生成时说明等待，不以实时局部记录推定最终结论。

专用页面使用 SC 区域代号。共同条件预览、实时记录、历史任务名称及完整证据通过 `coded-region-display` 生成只读展示内容，原始记录仍用于算例身份检查。转换仅作用于本专用入口，不修改其他页面或原始数据；下载文件的脱敏不在本次范围内。
