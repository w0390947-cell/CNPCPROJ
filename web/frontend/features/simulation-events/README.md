# 新能源事件操作

负责人：前端维护负责人；事件语义由仿真研究维护负责人评审。

公开入口 `index.ts` 提供 `RenewableEventControls` 和从生成契约提取的事件类型。
该功能只负责下一次新能源事件的区域选择、操作按钮与可访问的禁用原因；不计算物理变化，
不直接发请求，不修改或持有仿真结果。现有 `components/simulation-dashboard.tsx`
作为存量页面组合器消费公开入口，并继续负责基线与任务生命周期。

依赖仅为 React、图标库、shared 区域展示映射与生成事件契约；样式使用本功能 CSS Module。
不引入跨功能依赖，不复制区域名称或后端类型，不更改 API。

## 状态与兼容

- 集群态势首次默认使用已完成结果的 `request.region`（兼容历史结果）；用户显式选择后，
  在当前页面保留选择，选择本身不提交任务。离开页面后选择状态随组件销毁。
- 单微网目标始终来自当前已完成结果，不提供独立区域下拉框。
- 目标区域通过回调显式交付给页面组合器；新事件只改变 `events`，其余请求参数继承基线。
- 没有结果、没有可用回放点、服务不可用或任务运行时，选择与注入按钮一同禁用。
- 原有区域请求字段、结果和事件记录保持兼容；仿真区域草稿与事件区域选择互相独立。

模型含义见 [事件契约](../../../../src/oilfield_energy/modules/studies/contracts.py)，
操作说明见 [Web 使用说明](../../../../docs2/Web仿真系统使用说明.md) 第 5～8 节。

验证：`node --test tests/components/dashboard-result-identity.test.mjs` 覆盖真实 React 状态、
事件区域选择与提交参数（请求及通用组件作为端口替身），另执行严格类型、lint 和生产构建。
