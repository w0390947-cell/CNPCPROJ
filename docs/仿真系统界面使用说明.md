# 仿真系统使用说明

## 2. 单微网优化：从运行到查看结果

### 2.1 这个页面展示什么

“新能源最优协同控制算法仿真”页面专门展示一个固定的单微网核心实施例：十个网络节点，包含风电、光伏、储能和 SVG 等设备。仿真覆盖一天，共 1440 个一分钟执行周期；滚动规划按 15 分钟更新。这里的“分钟”是**仿真时间**，不表示电脑每计算一个周期必然需要现实中的一分钟。

页面会查找最近一次符合该实施例且已完整完成的可用结果，找到后自动显示。若页面地址明确指定了某个任务，则显示所指定的任务。结果旁的任务编号、来源及生成时间可用于确认当前查看的是哪一次记录。

### 2.2 开始、重新运行和取消

1. 页面没有已载入结果时，点击 **运行仿真**。
2. 已有结果时，可以查看该结果；需要重新计算时，点击 **重新运行仿真**。
3. 运行期间按钮变为 **取消仿真**。点击后等待页面显示取消状态。
4. 重新运行时，当前过程属于新任务。页面会提供“查看上一次完成的结果”链接，以便区分新任务与旧结果。

顶部的文字和进度条表示后台当前计算阶段及流程进度。滚动执行时还会显示窗口编号、对应的仿真时间范围及已完成窗口数。流程进度用于了解计算推进情况，**不等于已经耗费的时间比例，也不是运行安全结论**。

仿真先进行基准和优化方案等计算，随后才开始产生逐周期执行记录。执行记录产生后，主区域会逐步更新；计算完成后，同一区域显示完整结果。

### 2.3 “运行结果”卡片

结果生成后，主区域中的卡片概括以下结论：

| 卡片 | 如何理解 |
|---|---|
| 条件安全 | 在本次声明的设备模型、网络条件和扰动范围内，执行证据的安全状态。 |
| 目标接纳 | 控制器是否对本次目标请求取得可采用的接纳结果。 |
| 期限后跟踪 | 已接纳的 PCC 目标，在相应响应期限后的评价结果。 |
| 储能原期限任务 | 原定截止时刻的储能电量任务是否完成；下方另列任务保证是否持续保持。 |
| 计划成本改善 | 选定方案相对于无储能优化基准方案的**计划综合成本**改善百分比。 |

“通过”是对应项目在本次仿真假设和评价范围内通过；“未通过”表示对应检查未通过；“未确认”表示当前证据不足或尚未形成相应结论，不能当作通过。任务保证与到期实际完成是两个不同的信息，应分别看。

计划成本改善按同一输入和费用口径比较两个计划方案：`（无储能基准计划成本－选定方案计划成本）÷无储能基准计划成本×100%`。正值表示选定方案的该项计划成本较低；它不是实际电费节省，也不能单凭这个百分比认定现场经济性考核已经达标。

### 2.4 统一周期控制

“仿真运行过程与结果”区域提供一套共同的周期控制：

- **播放轨迹／暂停轨迹播放**：按已完成记录依次播放或暂停。播放到末尾后，再次播放会从起点开始。
- **查看上一周期／查看下一周期**：向前或向后查看一个已有周期。
- **选择执行记录周期**滑条：拖动到已完成记录中的某个周期。也可以点击图表，或聚焦图表后用左右方向键定位。
- **跟随最新周期**：恢复跟随不断产生的最新执行记录；手动选择周期后可用它返回最新位置。

`00:00`、第 0 周期表示声明的初始状态；第 `n` 周期表示完成第 `n` 个一分钟区间后的状态。计算中只能选择已经产生的记录。手动查看历史周期时，页面各数据保持在所选周期；跟随最新周期时，新记录到来后会继续更新。计算完成后仍使用同一套控制查看和回放。

### 2.5 设备卡片和当前周期状态

设备卡片分别展示风电、光伏、PCS 储能和 SVG 的汇总功率。`P` 是有功功率，单位 MW；`Q` 是无功功率，单位 Mvar。储能卡片还显示电量（MWh）和充电、放电或保持状态。设备图形的动态效果用于辅助演示。

卡片下方的当前周期信息包括：

| 信息 | 含义 |
|---|---|
| PCC P、PCC Q | 公共连接点功率的后台计算区间，分别以 MW 和 Mvar 表示。PCC 是微电网与上级电网的连接点。 |
| 本周期跟踪 | 所选周期处于响应过渡、已到期评价、保证区间外，或没有跟踪承诺等状态。 |
| 本周期网络校核 | 后台对所选周期网络端点的记录结果；没有对应记录时显示未记录。 |
| 当前执行方式 | 该周期使用经济反馈、原目标续接、备用续接或安全终态保持中的哪一种方式。 |
| 响应期限和保证终点 | 目标应达到的周期，以及本次证书覆盖的跟踪保证终点。 |
| 储能原任务 | 原定截止周期、目标电量区间和所选周期的当前电量。 |

周期中如果没有相应数据，页面会标记为未记录或未确认。图中和表格的数值来自所选的已完成仿真记录。

### 2.6 曲线与网络图

在“曲线对象”中选择 **按设备类型汇总**，可分别比较风电、光伏、储能和 SVG；选择具体设备后，可比较该设备的已完成出力和采用命令。

| 图表 | 查看重点 |
|---|---|
| 设备无功 / Mvar | 各类设备或所选设备的无功变化。 |
| 设备有功 / MW | 各类设备或所选设备的有功变化。 |
| 储能电量 / MWh | 电量轨迹、设备物理上下限、原任务区间及截止时刻。原任务区间是截止时刻要求，不意味着整个过程中都必须位于该区间。 |
| PCC P 跟踪 / MW | PCC 有功区间中点、外包上下界、评价目标及可用时的误差带。 |
| PCC Q 跟踪 / Mvar | PCC 无功区间中点、外包上下界、评价目标及可用时的误差带。 |

图表的横轴是从仿真开始累计的分钟，图例说明各条曲线。竖线标出当前选择位置；有记录时，图中还可标出响应期限 `D`、保证终点 `G` 或原任务截止 `T`。曲线连接用于阅读离散记录，不应据此推断周期内所有时刻均已通过连续跟踪证明。

“网络节点状态”以树形结构显示 PCC、主母线、风电、储能、SVG 和光伏等节点及其连接。节点框内的 P、Q 是接入该节点的设备出力汇总；电压 `V` 显示后台记录的区间。屏幕较窄时，可以在网络图区域横向滚动。网络图中的连线和设备动画用于演示，不能单独据此判断实际潮流方向或现场状态。

“所选周期设备状态”表按设备列出有功、无功和采用命令。点击其他周期或图表位置后，表格和网络图随同更新。

### 2.7 展开详细执行证据

点击 **详细执行证据** 可展开细节。计算中如果完整证据尚未生成，区域内会提示等待结果；结果生成后，可切换以下视图：

| 视图 | 内容和操作 |
|---|---|
| 设备实际响应 | 所选周期每台设备的实际 P/Q、命令、变化量、能力及可用功率；关键设备状态表中的周期编号可点击定位。 |
| PCC 目标跟踪 | 到期评价统计、所选周期误差及逐周期明细；可点击明细周期定位。 |
| 原期限电量任务 | 原任务区间、截止时间、当前及末电量，以及储能指令与电量更新。 |
| 滚动规划与接纳 | 选择规划窗口，查看窗口初始状态、候选计划、过渡见证、目标请求、接纳结果及候选比较。 |
| 网络与约束证据 | 查看所选周期的网络认证、节点电压、支路容量和设备状态范围；可展开输入负荷和风光可用量。 |

详细证据与主区域共用同一个周期。点击详细表格中的周期或切换规划窗口，会同时改变主区域的位置；在主区域切换周期，详细证据也会跟随。个别旧记录可能没有某些细节，页面会如实标明，不会用估算值补充证书。

## 3. 集群协调

集群协调页面展示三个区域之间的协同计算及模拟执行。常用流程如下：

1. 根据需要点击 **仿真参数**，查看或调整本次运行所用设置；点击 **完成参数设置** 返回。参数变更作用于下一次运行，不改变已经生成的结果。
2. 点击 **运行集群仿真**。计算期间可查看任务阶段和进度，也可点击 **取消仿真**。
3. 结果生成后，使用 **运行态势**、**协调过程** 和 **执行校核** 切换查看。它们共享同一次结果，切换视图不会重新计算。

三个视图各有侧重：

- **运行态势**：按计划时刻查看集群及各区域负荷、新能源和受电等数据。网络和区域卡片展示当前选择时刻的结果。
- **协调过程**：按 ADMM 算法迭代轮次查看区域申报、协调参考和收敛信息。算法轮次不是一天中的分钟，也不是滚动执行窗口数。
- **执行校核**：查看日前计划落实、日内更新和分钟级模拟执行的证据，以及可展开的安全、跟踪和恢复等记录。

“运行结论”区域列出各检查项，可展开查看说明；筛选功能可帮助定位未通过项。“通过”“未通过”“无法确认”和“未执行”应按各自含义阅读。结果可用时，可点击 **导出本次结果 JSON** 保存完整结果。

在有回放控制的视图中，底部控制栏可回到起点、播放或暂停、推进到下一条记录、切换回放速度并拖动时间轴。具体推进的是计划时刻还是协调轮次，以当前视图及控制栏标注为准。

### 3.1 新能源事件分支

在已有集群结果的**运行态势**中，可先用时间轴选择计划时刻，再在“新能源事件注入”中选择作用区域，点击 **当前时刻注入光伏大发** 或 **当前时刻注入风电大发**。系统沿用当前结果的基础参数创建新的事件分支并重新计算；页面可比较原方案与事件分支。事件区域的选择只影响下一次事件，原结果不会因为切换选择而直接改写。

## 4. 通信故障

通信故障页面用于观察失联、丢包或延迟等通信条件对协调过程的影响。可以通过 **仿真参数**设置关注区域、失联区间、随机丢包率及最大通信延迟等，再点击 **运行故障仿真**。

结果区域会展示通信报文、丢弃报文、自治降级、协调轮次等指标，并提供协调过程、运行结论及相关曲线。底部回放控制可以按页面当前模式选择记录。通信事件的说明会区分窗口完整执行、部分执行或尚未运行到该窗口，不应把未覆盖的窗口当成已经验证。

已有结果后，可在**协调过程**中选定轮次，使用 **当前轮次注入失联** 或 **当前轮次注入丢包**创建并计算事件分支。结果生成后，可以查看页面给出的原方案与事件分支对比，也可以导出结果 JSON。

## 5. 模拟设备演示

此页面让使用者观察模拟设备对命令和异常的响应。它的设备模拟回路与各算法页面的仿真任务是独立的：在“运行算法”提交任务，不等于将算法结果自动下发给模拟设备。

### 5.1 页面各区域

| 区域 | 内容 |
|---|---|
| 资料包、遥测帧和模拟时间 | 表示当前模拟数据身份、接收帧编号及模拟时间。 |
| 运行算法 | 使用预设提交单微网、三区域协同或通信故障任务；提交后通过出现的链接进入对应任务页面查看进度和结果。 |
| 实际出力的网络反馈 | 按区域显示 PCC 受电、电压范围、最大支路负载率、网损、功率因数及恢复闭锁状态；可展开支路明细。 |
| 当前资源与设备能力 | 根据选中的设备，显示当前可用功率、实际出力、输入目标、设备能力或储能电量。风电、光伏还可查看合成资源基准曲线。 |
| 下发模拟 P/Q 命令 | 选择模拟设备并输入命令，查看命令回执。 |
| 设备遥测 | 按设备列出接入母线、模拟有功、无功、可用功率和储能电量。 |
| 异常与恢复演示 | 切换模拟异常，查看连续安全周期并请求解除恢复闭锁。 |

### 5.2 发送模拟设备命令

1. 在 **下发模拟 P/Q 命令**中选择设备。
2. 先查看“当前资源与设备能力”，再填写 `P / MW` 和 `Q / Mvar`。
3. 点击 **发送至……**，查看页面提示和下方“命令回执”。
4. 继续观察“设备遥测”和“实际出力的网络反馈”，了解设备实际响应和网络变化。

P、Q 正值表示向网络注入；储能充电的 P 为负值。输入目标、命令受理和实际出力是不同的：设备实际能否达到目标，仍受当前可用量、设备能力、变化速度和安全条件约束，以回执及后续模拟遥测为准。命令有效期为十个**模拟分钟**。SVG 的有功固定为 0 MW，主要用于无功调节。

### 5.3 演示异常和恢复

在“异常与恢复演示”中，可选择正常通信、通信中断、坏质量遥测、电压跌落、回执丢失、负荷骤降、风机脱网或潮流不收敛等模拟场景。选择后观察网络反馈、设备遥测和闭锁状态的变化。

需要演示恢复时，先消除异常并等待页面记录至少两个连续安全周期，再点击 **请求解除恢复闭锁**，查看页面返回结果。解除闭锁后设备保持当前出力；如需新的目标，应另行发送命令。回执丢失或超时不能单独证明设备没有执行命令。

## 6. 常用单位和名词

| 名称 | 说明 |
|---|---|
| P / MW | 有功功率；在设备注入口径下，正值为向网络注入，储能充电为负值。 |
| Q / Mvar | 无功功率；正值按页面声明的注入口径表示容性注入。 |
| 电量 / MWh | 储能中保存的能量，与某一时刻的功率不是同一个量。 |
| PCC | 微电网与上级电网的公共连接点。页面中的 PCC 受电为从上级电网受入。 |
| SVG | 静止无功发生器，用于无功调节。 |
| PCS | 储能变流器；通过充、放电改变储能有功功率和电量。 |
| pu | 标幺值，即相对于选定基准的比值，常用于表示电压和负载率。 |
| 外包区间 | 后台在声明条件下计算出的范围；区间中点只是便于阅读的代表值，不等于现场测量值。 |
| ADMM 轮次 | 集群协调算法的迭代次数，不是仿真分钟或执行窗口数。 |
