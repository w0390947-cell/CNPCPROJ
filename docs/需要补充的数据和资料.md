# 区域型油田电网新能源协同控制研究所需甲方资料

本清单用于收集山城及其他选定区域的真实网络、设备、运行数据和工程接口资料，依次支撑固定时刻潮流分析、单微网与多微网协同优化、控制策略验证及D5000／SCADA工程应用对接。山城先行开展离线建模，其他入选区域按相同口径补充；资料收集不以在线接口或现场控制功能先行完成为前提。

依据项目[《技术要求及方案》](../docs3/3.1%20技术要求及方案（区域型油田电网新能源协同控制运行技术研究）630.docx)，研究需覆盖不少于3个微电网、不少于2个优化子目标，并评估考核点不倒送、平均考核功率因数0.9以上、电压要求及单微网运行经济性提升10%以上等目标。请提供具体考核对象、统计方法和比较基准，不能仅靠一份设备容量表或某一时刻的曲线判断上述目标是否实现。

烦请按以下阶段提供或确认资料。已提供且仍有效的资料，可注明文件名、版本和对应位置，无需重复整理。资料状态请逐项反馈，不默认本清单所列内容全部尚未提供。

| 批次 | 用途 | 资料范围 |
|---|---|---|
| 第一批：现场固定状态潮流 | 在给定某一时刻设备出力和负荷状态后，计算实际网络的电压、潮流、电流、负载率、损耗、PCC受电/倒送及功率因数 | 实际拓扑和参数、设备接入、同期P/Q、测点口径、运行方式、边界电压及校核量测 |
| 第二批：多时段优化与协同控制仿真 | 分析并优化风光储SVG的运行安排 | 在第一批基础上，补充预测或可用出力、调节能力、储能状态及优化目标和约束 |
| 第三批A：工程接口与只读联调 | 确认D5000／SCADA及站端系统的数据交换与状态反馈方式 | 接口资料、点表、遥测遥信、时标和质量码、通信性能、只读测试样例 |
| 第三批B：控制命令与受控联调 | 验证指令、回执、实际响应和异常恢复的完整过程 | 遥控遥调点、控制权限、命令语义、回执及返校、闭锁复归、测试范围与验收记录 |

第一批可先选取一个资料完整的实际运行时刻，打通计算流程，再扩展到一段代表性连续运行时段。第二批可随后补充。文中P指有功功率，Q指无功功率；额定容量不能替代某一时刻的实际P/Q。

## 研究范围与交付优先级

请先确认山城及另外至少两个参与评估的实际微电网：区域和场站名称、稳定编号、上级电网、各自PCC/考核点、包含的设备和管理层级。具体入选区域由双方确认，程序中的`SC`、`YA_B`、`YA_C`等算例标识不替代现场范围确认。

请说明这些微电网之间是否存在实际电气联络、是否共用受电通道或上级考核约束，以及协调中心与各区域控制器的关系。只有信息协调关系的区域，不应为构造“集群”而虚设电气联络线或共同容量上限。

资料按用途区分优先级：

- **P0 首批必需**：所选网络范围的接线与参数、完整设备/负荷接入关系、可用的固定运行点、点表口径、实际运行方式、边界电压及确认依据。缺少关键项会阻断相应现场潮流计算。
- **P1 对应阶段必需**：独立校核量测、多时段预测与实绩、设备能力、经济性基准、集群约束和控制逻辑；第三批接口资料也属于进入对应联调阶段前必须明确的内容。不要求在第一次固定潮流计算前一次交齐。
- **P2 按研究需要补充**：更长历史、气象原始数据、专门动态试验、短路/暂态资料等。若最终选用的模型依赖其中某项，再明确列为该项研究的必需输入。

以上是交付安排，不改变项目技术目标。多区域资料不齐时，可先完成山城工作，但不能据此声称已完成不少于3个实际微电网的评估。

## 第一批：现场固定状态潮流所需资料

以下第1～6节以P0为主；第7节是现场结果验证所需的P1资料。每个入选区域分别提供，山城可先交。下文涉及两台5MW风机、2.5MW/5MWh储能等特定配置时指山城；其他区域按实际在役设备逐项提供，不要求具有相同配置。

### 1. 实际一次接线图、网络范围及设备接入台账

请提供能相互核对的一次系统接线图和设备台账，并明确：

1. 本次建模的区域边界，山城变各电压等级母线及母线分段、母联关系；母线名称、编号和额定电压。
2. 主变压器、升压变压器、线路、馈线、开关的实际连接关系及起止母线；并联回路、联络线路和常开点也请保留并注明状态。
3. 区域分布式光伏的场站或设备清单、实际装机容量、接入变电所、母线、馈线、间隔及相关变压器。若只能提供聚合资料，请注明聚合成员及计量边界。
4. 两台5MW风机分别的设备名称、唯一编号、接入母线、间隔及升压变压器。即使接在同一母线，也请分别列出两台设备。
5. 2.5MW/5MWh储能及SVG的实际设备编号、接入母线、间隔、连接变压器和额定参数；请确认SVG实际容量，避免沿用合成算例的预设值。
6. 建模范围内负荷接入位置及馈线/母线归属，除主要负荷外，还需说明其余负荷、站用电等如何计入。若采用负荷聚合，请提供成员范围。
7. 山城微电网与上级电网的PCC、考核点及计量装置具体位置。若物理并网点与考核计量点不同，请分别标出，并说明两者之间设备和损耗的归属；多个边界连接点请逐一列出。

图纸、台账、测点表和历史数据中的同一对象应能对应。现有编号不统一时，请提供名称/编号对照表，并注明资料版本、生效日期及后续改造情况。

请附现行模型、台账或接线关系的确认记录，包括确认部门/人员、日期和适用范围。研发方负责整理软件记录，不能用程序“校验通过”替代甲方对资料真实性与有效性的确认。

### 2. 线路、变压器及其他网络设备的电气参数

以下参数用于定量计算，不能仅作为“如方便提供”的附件。若没有整理好的参数表，请提供能够确定参数的设计、厂家或试验资料，由双方核对换算结果；无法确定的项目请列为待补或待确认。

| 对象 | 请提供或确认的内容 | 用途及口径要求 |
|---|---|---|
| 母线 | 编号、额定电压及适用电压运行范围 | 建立电压基准、输出kV并判断电压越限 |
| 线路/电缆 | 编号、两端母线、长度、型号、并联回路情况、电阻R和电抗X | 明确R/X为整段值还是每公里值，以及单位、参数来源；若使用标幺值，注明电压和容量基准 |
| 线路运行限值 | 允许电流、适用运行条件；已有容量或调度限额 | 区分设备额定值和实际运行限值，并明确负载率考核采用电流还是容量口径 |
| 变压器 | 编号、各侧母线、额定容量、各侧额定电压、接线组别、短路阻抗及其基准 | 请提供可确定R/X分量的电阻/电抗参数，或短路试验损耗等资料；多绕组变压器注明各绕组和成对试验参数 |
| 变压器分接与限值 | 分接侧、档位范围、步长、档位与变比对应关系、正常档位、允许负载 | 支持实际变比和负载率计算；计算时刻的实际档位另见运行状态资料 |
| 并联补偿及其他设备 | 电容器、电抗器等的接入位置、额定电压、容量、分组情况及运行限值 | 计入实际存在且属于研究范围的设备，并区分固定补偿与SVG |

线路充电参数、变压器空载损耗及励磁参数如有现成资料，请一并提供；是否纳入计算模型，由双方结合线路类型、研究范围和精度要求确认。不能将缺失参数默认解释为零。

母线短路容量或短路等值不能替代各条线路、变压器的R/X。短路资料仅在选定的上级电网等值或相关研究依赖它时补充，不作为所有离线潮流计算的统一前提。

### 3. 同一时刻或同一时段的设备出力与负荷数据

请提供实际数值记录及时间戳，优先使用可导出的Excel/CSV历史数据。每个记录应能通过设备或测点编号对应到接入台账。

| 对象 | 请提供的数据 |
|---|---|
| 两台风机 | 分别提供实际P、Q、运行/停机状态；限发期间注明限发状态 |
| 分布式光伏 | 按实际场站或经确认的聚合范围提供P、Q及运行状态 |
| 储能 | 实际充放电P、Q、充电/放电/待机/停运状态，并解释正负方向 |
| SVG | 实际Q、投退状态；若有单独有功损耗量测，请说明其数值及是否已计入其他负荷 |
| 负荷 | 对应母线、馈线或负荷对象的P、Q，以及计量覆盖范围 |
| 其他注入或用电 | 研究范围内其他电源、站用电等的P/Q，或说明已经归入哪个计量对象 |

请先共同选定一个数据较完整的运行时刻，再提供一段能覆盖昼夜负荷、光伏变化及储能充放电的代表性连续时段，例如一个完整运行日。存在风电明显变化、倒送或补偿切换的有效记录时，可补充相应时段；具体窗口和采样间隔按现场数据可用性协商。

若没有直接测量Q，请提供可推导Q的同期数据，并说明功率因数定义及无功吸收/注入方向；仅有功率因数绝对值不足以确认Q方向。缺少相关量时，由双方确认估计方法，并在结果中标明，不能直接套用合成算例的固定功率因数。

当前固定时刻入口需要每个设备明确的P、Q及投运状态，每个负荷对象需要P/Q，边界需要PCC电压。停运时应有明确的状态及零出力依据；SVG有功忽略、设备无功固定为零等简化，也应由双方确认并标注为模型约定，不能自动把空白量测补零。确实没有负荷的母线请明确确认“无负荷”；不能把缺少负荷数据解释为无负荷。

对于只有馈线总量、没有内部负荷分项的数据，请说明可用分项计量及统计依据。需要按比例分配或等值时，应确认分配范围、比例来源和适用时段；不能仅凭总量认定已获得真实逐母线负荷。

### 4. 测点对应关系、单位、方向及时间含义

请提供历史数据字段说明或现有测点表，使每一列数值都能对应到实际对象。可按下表列项整理：

| 项目 | 请说明的内容 |
|---|---|
| 测点与对象 | 测点编号、名称、对应设备/母线/馈线/变压器；支路量测注明在哪一端或哪一侧 |
| 文件位置 | 文件名、工作表、列名；若为系统导出，注明原系统测点编号 |
| 物理量 | P、Q、电压、电流、功率因数、SOC、电量或状态；区分功率与累计电量 |
| 单位与倍率 | kW/MW、kvar/Mvar、V/kV、A、kWh/MWh、SOC百分数或小数等；原值是否已乘CT/PT及其他工程倍率，避免重复换算 |
| 电压与相别 | 线电压或相电压、三相总量或分相量；提供分相数据时注明相别 |
| 正负方向 | 各测点P、Q分别的正方向；储能充放电、PCC受送电及无功容性/感性口径；状态码的含义 |
| 时间含义 | 时区、采样周期、时间戳对应瞬时值还是区间平均值、区间起点还是终点，以及各系统时间是否同步 |
| 质量标记 | 缺测、通信中断、无效值、停运零值、估计值及人工修正的标识；数据是否已经插值或平滑 |
| 有效范围 | 映射和倍率适用时间、修改记录及资料版本 |

不同测点不必事先人工改成统一单位，但必须能解释原始口径。存在时间偏差时，请说明已知偏差，由双方确认对齐规则；小时平均值不能当作某个瞬间的实测值，也不能通过重复填充宣称获得真实15分钟量测。

请同时约定单点量测允许的最大年龄、多个测点之间允许的最大时间偏差，以及质量码映射依据；时间容差使用秒。当前固定时刻入口仅直接接受瞬时量，选择不晚于计算时刻的最新记录并检查质量；不会自动插值、用预测替代实测或在最新值无效时退回更早的有效值。若只有区间平均数据，应先确认适用分析及所需适配，不能改字段名称就当作瞬时值。

### 5. 计量范围与上下级包含关系

请明确每个“负荷”“馈线功率”“场站功率”测点的计量边界：

- 数值代表纯用电负荷、设备发电出力，还是已经包含下游新能源和储能的净交换功率。
- 该测点覆盖哪些设备和下级测点，与上级或其他测点是否重叠。
- 数值是否包含线路、变压器、站用电或设备损耗；风机、光伏和储能的量测在设备端还是并网端。
- 哪些量可用于构造计算输入，哪些可留作独立校核；最终用途由双方结合数据覆盖情况确认。

例如：馈线内负荷5MW、光伏发电2MW，忽略损耗时入口净受电约3MW。该3MW不能被当作纯负荷再扣除一次2MW光伏。因此，请同时提供计量边界说明，而不只提供“馈线负荷”这一列名称。

### 6. 计算时刻的运行方式与上级电网边界

除正常运行方式外，请提供所选时刻或时段实际发生的：

- 开关分合、母联/联络线状态、线路及设备检修投退；连续回放时提供初始状态和带时间戳的变更记录。
- 变压器实际分接档位、并联补偿分组投退及其变更时间。
- 并网、解列或孤岛状态；存在多个并网点、合环运行时明确各连接点及对应时段。
- 作为计算边界的上级电网连接母线同期电压及其量测位置、单位；缺少实测时，请确认可采用的电压设定及依据。
- PCC/考核点P、Q正负方向，计量归属、损耗处理方式，以及适用的电压、负载、受电/倒送和功率因数考核要求。请注明考核点、统计周期、适用工况及文件来源；未明确的要求列为待确认。

对于历史回放，需要的是历史计算时刻的实际方式，不能仅用当前正常方式代替。现场若存在环网、特殊变压器相移或三相不平衡研究需求，请按实提供，由研发方检查求解方法的适用性并决定是否扩展模型。

对“平均考核功率因数0.9以上”，请确认考核采用同期电量还是瞬时功率统计、平均方式、统计周期及低负荷/零交换时段处理；对“不倒送”请确认考核时间分辨率、测量容差和经批准的边界；对电压请确认各电压等级和工况的限值来源。当前程序默认限值及逐时刻功率因数不能直接替代甲方的正式考核口径。

### 7. 用于验证结果的同期量测

请提供可获得的同期PCC有功、无功、电压及功率因数，其他母线电压，以及线路、变压器两侧P/Q、电流等记录；已有可信的潮流计算报告，也请附上对应输入、时刻及模型版本。

这些资料用于比较计算与现场的差异，不要求每条支路都有完整量测才能开始计算。请说明仪表或导出数据已知的精度、质量问题，并由双方约定比较对象和误差评价方法。

用于反推负荷或校准参数的量测，应明确标记其用途；不能只用同一批反推依据证明计算准确，还需尽可能安排独立量测或其他时段校核。数据不足时，应说明能够验证的范围。

## 第二批：多时段优化与协同控制仿真补充资料

本批资料属于相应优化与控制研究的P1输入。仅做给定P/Q的固定状态潮流时，不要求先备齐；评估运行经济性、集群协同或控制恢复时，则需明确对应输入和比较条件。

### 1. 预测、可用出力和运行实绩

| 资料 | 请提供的具体内容 | 用途及关键口径 |
|---|---|---|

无量测、缺失、通信异常与真实零值分别标识，不需要用猜测值填满表格。估计、插值、负荷分配、设备聚合、约定边界电压等处理需记录依据和确认结果；允许在明确假设下推进研究，不将其表述为全部由现场实测支撑。

## 资料交付、软件适配与验证分工

甲方提供并确认工程事实、原始资料、适用业务规则和接口条件。图纸、Excel/CSV及字段说明即可先推进离线工作，无需甲方编写Python、构造软件模型对象或自行生成文件摘要。

研发方负责资料差异检查、单位方向转换、时间语义处理、计量去重、结构化网络和设备映射、输入版本与摘要、求解适配、接口实现和结果归档。将缺项及不支持的模型明确反馈给甲方；新设备模型、环网等网络扩展和新协议接入分别安排开发，不能通过补默认值绕过。

双方共同确认估计与简化依据、经济性比较基准、控制阈值、接口字段及现场结果误差评价。资料齐备、文件校验通过、潮流收敛、运行约束满足、接口联调通过和现场验收是不同阶段的结论，应分别留档。
