# 区域型油田电网新能源协同控制研究所需甲方资料

本清单适用于山城及其他入选微电网。请按实际区域和设备提供全部适用资料，不分提交批次。通用要求见第2～7节；第8节只列区域特有的资料缺口和待澄清事项。

依据[《技术要求及方案》](../docs3/3.1%20技术要求及方案（区域型油田电网新能源协同控制运行技术研究）630.docx)，研究范围应覆盖不少于3个实际微电网、不少于2个优化子目标，并明确考核点不倒送、平均考核功率因数0.9以上、电压要求及单微网运行经济性提升10%以上的适用对象和正式口径。

## 1. 统一提交要求

- **适用对象**：各区域分别注明实际设备及研究范围。光伏、储能、SVG、可调负荷等不存在或不纳入研究时，请明确说明；按需项目依其适用条件提供。
- **资料标识**：每份资料注明对应清单编号、区域/设备、覆盖时间、来源、版本或导出日期、生效日期及确认部门/人员。图纸、台账、点表中的名称、编号、接线或倍率不一致或有变更时，附对照及改造/变更生效时间；口径或版本冲突注明差异和当前有效依据。
- **已有资料与缺项**：已有且仍有效的资料只需注明文件、页码/图号或工作表位置，同一文件可对应多个条目，无需重复提交。待提供、待确认、无量测或不适用的项目注明对象、字段、时段、原因及可用替代依据；如能确定，注明预计补充时间。
- **文件形式**：图纸可提供PDF或原始CAD；台账、点表和时序数据可提供Excel/CSV或系统原始导出文件。保留现有文件结构并提供索引即可，截图、汇总值或无字段说明的曲线图不能替代可获得的原始数据。
- **表格格式**：时序数据可采用带时间列的宽表，或“时间戳、测点编号、数值、质量标记”的长表，附字段说明。CSV建议使用UTF-8；Excel注明表头、工作表、数值单元格和日期系统，公式列保留有效计算值。厂家专有格式或特殊时间编码需附解释。
- **原始记录**：保留原始文件和采样间隔。转换、聚合、估计、插值、平滑、人工修正或采用简化的资料，分别标记并附方法、依据及确认记录；缺失、通信异常、无效值与真实零值分开标识。

文中P为有功功率，Q为无功功率，S为视在功率/容量，SOC为储能荷电状态；额定参数与实际运行量分别提供。
