# 延安资料参考网络等值

模型标识：`YA_B-reference-synthetic-network-v1`、`YA_C-reference-synthetic-network-v1`。参数实例：`oilfield-unified-synthetic / 2026-09-21-v1`。维护责任：项目技术负责人（台账）、仿真研究维护负责人（算例）；电气复核归潮流计算维护负责人。

## 输入、输出及适用范围

权威输入为[统一台账](../../src/oilfield_energy/bootstrap/assets/unified_dataset.json)中的设备、母线、支路、电容器与来源。源文件摘要、页码、拓扑图和剩余模拟配置见[数据说明](../统一模拟数据说明.md#延安资料参考模型2026-09-21)。本模型是显式构造的研究等值，没有运行时自动环网转树。

输出为当前平衡正序径向求解器使用的网络台账及兼容视图，由[统一装配](../../src/oilfield_energy/bootstrap/adapters/project_dataset.py)经[优化输入适配](../../src/oilfield_energy/bootstrap/adapters/simulation_case.py)构造。P/Q用MW/Mvar，S用MVA，电压基准用线电压kV，阻抗为20 MVA基准标幺值；母线和设备按ID映射。内部设备注入为正、负荷消耗为正、PCC受电为正。

两地分别把35 kV、10 kV分段母线合并，并以同变比双主变并联等值。化子坪风机T接位置按线路中点，远端负荷为模拟聚合；榆树风机接入35 kV母线。仅选定一条供电路径，其他联络线不进入本研究方式。该近似适用于当前算例的稳态优化与模拟执行，不还原现场独立开关、环网、孤岛、三相不平衡、零序和保护动作。尚无同期量测，无法量化相对真实电网的等值误差。

## 参数换算

**换算与假设：**统一base为20 MVA；35 kV线路Zbase=35²/20=61.25 Ω。资料没有给出正序R/X，LGJ-95暂取模拟r=0.32 Ω/km、x=0.40 Ω/km，以长度换算为整段标幺值；不是厂家实测或已核准的标准参数。线路MVA上限按√3×35 kV×允许电流换算，是额定电压处的容量代理，当前优化器并未将其作为随电压变化的恒电流约束。PCC位于所选供电线路上级端的模拟等值边界，包含线路损耗，不能直接对应甲方尚未确认的站端计量点；内部受电为正，资料的“母线指向线路为正”须按实际点表转换。

变压器在各自容量基准上，`z_i=(r_i+j√(uk_i²-r_i²))×20/S_i`，并列后`z_eq=1/Σ(1/z_i)`。化子坪第二台r=0.04628/8=0.005785；第一台缺负载损耗，取模拟r=0.01。榆树第一台缺负载损耗，第二台表中“81.5”未印单位，两台r均暂取模拟0.01，未擅自按kW使用该数值。空载损耗和空载电流不代替串联电阻，当前未建励磁支路。

化子坪等值R/X为0.01082157687/0.10276499835 pu，榆树为0.00888888889/0.06768548908 pu。化子坪两台阻抗不一致，容量上限按`min(S_i/abs(z_eq/z_i))`取约13.9742 MVA，避免简单相加14.3 MVA时使其中一台超载；榆树等值上限22.5 MVA。35/10.5 kV铭牌与35/10 kV系统基准不同，固定非额定变比采用`(35/10.5)/(35/10)=10/10.5`，不将35/10.5直接填入标幺变比。实际档位及两台独立调压范围未建模，不声称并列可行性已现场核实。

## 电容器、限值与拒绝条件

资料电容器容量按kvar/1000转换为Mvar，合并到10 kV等值母线；具体分组为研究表达，默认全部退出不代表现场状态。显式投入后，既有网络模型按`Q=Q_nominal×|V_pu|²`计算容性注入；不与独立模拟SVG的无功重复记为同一设备。

线路与变压器热限、电压上下界、PCC上下界、设备能力共同限制优化可行域；不因未收敛或不可行而自动增大限值。改变运行方式后不满足连通径向条件时，由[网络模型](../../src/oilfield_energy/network_model.py)拒绝，不补造连线。当前电流换算只形成额定电压MVA代理限值，精确电流约束需另行建模。主变损耗分流限值为固定正序等值条件下的近似，不覆盖温升、环流或不等档运行。

## 验证与边界

[资料与换算测试](../../tests/integration/studies/test_yanan_reference_data.py)核对源容量、T接关系、长度/电流单位、主变手算参考值、额定与基准电压差别、电容投退、捕获包一致性；[跨入口测试](../../tests/integration/studies/test_unified_dataset.py)运行真实单微网/集群求解。全日96点优化和1440分钟集群执行记录见[数据说明的验证记录](../统一模拟数据说明.md)，原始证据位于`artifacts/yanan-source-alignment/`。通过软件回归不表示现场模型已校准，集群跟踪检查未通过时仍保留其真实结果。
