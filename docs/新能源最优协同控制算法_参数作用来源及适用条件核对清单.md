### 1.1 性质分类

| 标记 | 含义 | 判断原则 |
| --- | --- | --- |
| 物理／运行条件 | 设备能力、电网关系、授权范围或运行要求 | 如容量、能量上下限、支路限额、功率平衡。关系需要保留，具体数值随现场变化。 |
| 配置参数 | 由任务、模型、策略或计算预算输入的参数 | 可输入不等于任意值都可行，更不等于修改后可以沿用旧证书。 |
| 算例取值 | 某一验证场景使用的具体值 | 用于复现该算例，通常不应成为所有应用的统一数值要求。 |
| 模型／证明条件 | 当前数学模型或充分性论证成立的前提 | 如径向准静态、共同无功响应系数、末预测包络持续。不能只删除文字就认为限制消失。 |
| 实现边界 | 当前程序强制接受的结构、范围或有限构造 | 如一分钟网格、PCS 有功系数必须为 1、有限搜索次数。不是普遍物理规律。 |
| 结果量／派生量 | 根据输入计算得到的量，或一次验证输出 | 不宜写成必须预先设置的参数。 |

一个条目可以同时属于多类。例如，跟踪容差是任务配置参数，`0.05` 是算例值；整定阈值是模型参数，`≤0.001` 同时是当前代码的实现边界。

### 1.2 “代码支持”口径

区分“底层契约可输入”“默认装配固定”“现场接口可输入”“代码强制”“计算派生”和“尚未提供通用实现”。不能因为某个底层函数有一个参数，就认为所有入口都支持修改它。下文用 C01～C25 标注代码依据，具体文件链接见第 11 节。

### 9.2 应保留原理关系或前提，不能只删除限制

1. 功率平衡、容量、能量界、效率换算、单位与正负号必须明确；具体容量和上下限随项目输入。
2. 固定 P 首步充分性依赖恒定命令、共同时间常数和能力条件。更换假设，不能原样保留推导结论。
3. 现有有限到达和能量不漂移结论依赖当前整定／PCS 保持模型。移到实施例后，通用段也应明确“依选定模型重新校核”。
4. 不变终态、末预测包络持续、准确及时状态与命令执行，是当前条件安全论证的前提；不能仅以“适用于实际设备”一句代替。
5. 任务 `[L,U]、T` 及已接纳目标的误差带、期限不能因失败自动重置，这是方法逻辑，不是某个算例的任意数值。
6. 10% 是单独经济评价指标；算法获证安全、完成任务不推出经济指标必然达到，也不推出完整物理轨迹集合上的全局最优。
