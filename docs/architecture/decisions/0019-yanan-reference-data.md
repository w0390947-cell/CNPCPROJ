# ADR 0019 延安两区资料参考型模拟数据

日期：2026-09-21。范围：经用户确认，YA_B参考化子坪、YA_C参考榆树；允许保留资料缺失部分的模拟设置。

状态：accepted（研究实施决策，不是现场批准）。维护责任沿用模块登记：台账为项目技术负责人，算例为仿真研究维护负责人；电气模型需潮流计算维护负责人复核。

## 背景与备选方案

原延安两区均为同结构的五母线35 kV合成网，风机7/6 MW与选定资料中的5 MW不一致。只改容量会遗漏明确的电压层级和接入差别；逐条照搬站图又会在缺少负荷、开关状态时假造完整现场网络。选择有来源且明确近似条件的研究等值，兼顾资料利用和当前求解器适用范围。代价是无法评价未纳入的分段、联络线、独立调档及真实站级运行方式，仍需后续资料闭合。

## 决策

继续由`bootstrap/assets/unified_dataset.json`唯一维护默认参数，内容revision升为`2026-09-21-v1`，已有v2字段足以承载网络、额定值、并联电容及来源，不新增配置层、业务模块或运行时PDF读取。

两地各采用资料明确的一台5 MW风机、35 kV接入、35/10 kV分段站级关系及主变容量/短路阻抗。为现有平衡正序径向求解器建立七母线六支路等值：同电压母线合并、选定一条供电路线、双主变在假定同中性变比下并联等值；化子坪显式保留化镰线路T接与远端支路，榆树为站内35 kV接入。不得把这份研究等值当成完整现场一次图。

线路采用资料中的长度、型号及允许电流，缺失的每公里R/X明确模拟；按额定电压把电流换算为MVA代理限值。主变从自身容量基准换算至20 MVA，按分流比例限制等值容量，并区分10.5 kV铭牌二次电压与10 kV系统电压。负载损耗缺失或单位不明时不臆测实测R；空载损耗不充当短路损耗。来源页码及摘要见[统一模拟数据说明](../../统一模拟数据说明.md)，公式与适用域见[模型说明](../../modeling/yanan-reference-network.md)。

登记资料已明确的固定电容容量，默认退出为模拟假设。保留现有光伏、储能和SVG研究扩展、负荷总规模及曲线生成规则，逐项记录未被当地资料确认。风电按5 MW重新生成，S和绝对Q沿用原模拟能力比例。既有设备ID稳定，母线位置与网络版本显式变化。

延安沿用33.3%风机比例；不将山城30%当作默认。既有执行底座的山城式就地时段、充电功率和SVG回退目标仅作为沿用的模拟控制假设登记，未获得延安现场规则，因此不在本次数据调整中改造状态机或声称策略已经本地化。待补清单要求确认各区域真实策略、设备及适用边界。

## 兼容与验证

SC除统一revision外参数保持不变。历史输入、设备包与结果从自身捕获数据解码，不注入新容量、接线或参考地名；全局YA展示名称不变，当前算例说明页解释参考映射并使用生成参数投影。说明页不是旧结果的数据说明。

资料和单位换算回归在`test_yanan_reference_data.py`，跨入口一致性、实际单微网/集群求解及历史兼容复用原影响集测试。核验新旧SC数据和YA负荷时序，运行延安全日优化及集群执行；测试通过仅表示本研究模型自洽，不等于现场精度、就地策略或运行限值确认。证据存入`artifacts/yanan-source-alignment/`。
