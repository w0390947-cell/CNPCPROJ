# ADR 0016 风电计划无功展示

状态：accepted；日期：2026-09-20；负责人：Web展示与结果契约维护负责人。

## 背景与决定

单微网拓扑的风电计划只展示有功，优化器已有的区域无功汇总未进入展示接口。新增`TimeSeriesPoint.wind_q_mvar`，单位Mvar，正值为注入、负值为吸收；新结果直接读取采用优化结果，不用30%或33.3%能力上限估算，也不取绝对值后求和。

该字段可缺失或为null，以兼容历史结果；缺失显示“—”，计算得到的零显示“0.00”。前端时序传输类型改为由Python权威类型生成，回放视图保留自己的轻量投影。P/Q使用同一结果、区域与时间轴，沿用已有线性插值，任一端点缺失不补造Q。插值仅用于计划回放，不作为设备实绩或新优化解。

局部样式放在网络拓扑功能包内，保留功能分组布局。没有新增跨模块业务依赖，没有变更求解约束。缺失值默认零和按比例推算都会误述历史或优化结果，故不采用。

## 兼容与验证

新增可选字段保持旧结果可读，不改写原始归档；现有Web客户端按需读取字段，可忽略新增字段。旧版严格拒绝未知字段的Python契约不保证能读取新归档，回滚时需保留配套解析器或读取原有旧归档。同步生成OpenAPI、结果JSON Schema及TypeScript类型。验证两种优化后端的区域汇总传递、正负Q及零值、历史缺失、回放同步、组件结果身份、静态检查及前端构建。
