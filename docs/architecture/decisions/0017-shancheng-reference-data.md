# ADR 0017 山城资料参考型模拟数据

日期：2026-09-20。决策范围：用户授权的山城模拟数据对齐；不代表现场参数批准。

## 原因

统一台账原先将山城风储SVG接入10 kV主母线，SVG额定和调节边界均为2.5；两份项目PDF明确展示35 kV微网接线、SVG容量2 Mvar及山城调节边界±1.8 Mvar。事实注册表已有SVG控制值，但业务模拟未采用。设备演示装配还把Q上限复制为S容量，使两种语义无法区分。

## 决策

- 只在`bootstrap/assets/unified_dataset.json`维护业务默认数据，数据revision升至`2026-09-20-v3`。既有v2契约已有设备、网络和来源字段，沿用模式，不新增并行配置、运行时PDF解析或领域文件读取。
- 建立35 kV微网主干、风电汇集、独立储能与SVG支路。模拟光伏及负荷继续保留，形成十母线九支路径向等值。SVG、风机节点代表35 kV侧等值，不声称为设备机端电压。
- 不复制西交大资料第4页站内主变为微网主变，不猜测站级并列运行方式。原六组负荷及光伏研究配置是额外模拟假设，PCC及经济结果仅适用于这个扩展算例。模型边界和原始PDF摘要集中记录在[统一模拟数据说明](../../统一模拟数据说明.md)。
- 用既有S和Q字段分别表达SVG 2 MVA额定容量和±1.8 Mvar控制边界；本地容性目标1.5 Mvar保持在既有控制配置。设备演示装配通过公开`svg_capability()`传递S，避免再将Q当作S。PV与储能的模拟Q边界按资料归零，优化和分钟执行仍采用原有禁用Q控制。
- 风机5 MW额定有功记录资料依据，5.25 MVA和1.64 Mvar仍标记模拟；SOC、线路R/X、热限、电压判据、曲线和电价等未确认项继续模拟。时段冲突沿用正文20–23时，不据15%–85%图注擅自确认SOC。
- 分别保留设备ID和母线映射。SVG仍使用既有设备ID，母线移到`SC_SVG`；新网络ID和数据revision防止将新旧接线混淆。YA_B、YA_C只更新所属统一数据revision，参数不改。

## 兼容与限制

历史捕获包、配方和归档继续读取自身参数，不重写或注入新拓扑；前端的五张功能分组卡片不是电气节点数，无需为十母线模型改动布局。Web参数投影由现有工具重新生成。

开关常闭为本算例假设，打开后若失去连通性应明确拒绝当前求解，不进行隐式环网转树或孤岛分析。新的支路阻抗全部属于模拟假设，无可用于评估现场等值误差的量测，不能声明已完成现场校准。

## 验证

资料约束回归位于`tests/integration/studies/test_shancheng_reference_data.py`；跨入口和真实求解位于`test_unified_dataset.py`；完整短窗口研究验证固定潮流、日前/滚动优化、分钟SVG边界、异常及群控。实际运行范围和结果记录在统一模拟数据说明及`artifacts/shancheng-source-alignment/`，不将历史全日研究当成本次全日验证。
