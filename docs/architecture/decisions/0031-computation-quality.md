# ADR 0031：集群采用质量优先的有限计算预算

状态：采纳。日期：2026-09-27。

用户希望集群仿真充分展示模型能力，无需手动决定求解时限或 ADMM 轮数。直接放大两个默认值不能识别可行与最优性精度，也无法解释为何停止。

采用版本化后台策略：SCIP 仅因时限不足且质量未满足时分级重试；ADMM 在同一迭代状态下增加累计预算。公开质量规则和轻量证据契约归 dispatch；已登记旧数值适配器负责求解调用，服务与 cluster_execution 传递策略及审计记录。前端普通侧栏删除两个控件，只在结果中展示实际质量与预算。

历史策略缺省 None，保留原手动请求语义；新网页集群请求显式选择策略版本，其他场景不变。不放宽 gap、残差或安全阈值，不自动重试不可行、数值异常、取消。保留可用但不充分的解和 unknown 状态，未达到质量要求的区域计划不采用。

代价：困难模型计算时间可能增加；SCIP 预算重试当前重新构造同一模型，未复用搜索树。ADMM 延续不丢失状态。保护上限仍有限。达到指定 gap、协调收敛、执行通过不合并成全系统全局最优声明。参数、边界与验证详见 [计算质量说明](../../modeling/Computation_Quality.md)。
