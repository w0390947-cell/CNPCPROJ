# ADR 0028：分钟有功反馈的跨资源接续

日期：2026-09-25。负责人：设备控制维护负责人；复核：潮流计算维护负责人。

## 问题

山城 96 点集群运行在储能到达最低能量后出现 PCC 有功超差，虽然光伏仍有可用余量，
其普通执行仍被计划出力封顶，反馈主要依靠储能，缺少资源之间的接续分配。

## 决策

在控制模块新增无 I/O、无求解器的剩余偏差分配用例及不可变契约，通过已有登记的
`device_control.py → control.api/contracts` 边界接入。数值桥保留状态机与网络评价
编排，不把控制模块反向耦合到潮流模块。模型和限制见
[Active_Tracking.md](../../modeling/Active_Tracking.md)。

保留储能优先，剩余修正按光伏、风机组顺序提出候选；设备计划与能力边界分别表达。
严格保留 owner 限额、恢复闭锁、额定能力、同周期动态额度及网络检查；未经检查的
候选不成为执行实绩。控制输出增量证据记录在既有网络执行记录中。

## 兼容与代价

公开结果增加可空的算法版本字段并从权威类型重新生成契约。旧文件读取为 None。
普通执行结果可以因新分配而变化，原计划目标与校核阈值不变；没有新的用户操作。
新增候选潮流评价会增加少量执行计算。策略为保守顺序分配，不是每分钟全局优化；
原有储能计划、风机组分解以及无功动态控制仍适用，不保证所有剩余未通过项被消除。

验证覆盖单元守恒和动态边界、真实网络集成、保护/恢复回归及完整 96 窗口复算。
