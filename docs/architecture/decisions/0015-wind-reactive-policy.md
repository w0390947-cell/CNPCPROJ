# ADR 0015 风机无功策略与设备容量分离

状态：accepted；日期：2026-09-20。负责人：设备建模维护负责人；复核：优化调度、设备控制维护负责人。

## 背景

《西交大-资料提供.pdf》第9页给出一般风机无功范围为有功的0%至33.3%；《山城微电网控制策略逻辑.pdf》第3、5页采用0.3P计算调节裕度。原统一模拟以`min(0.328, Q额定/P额定)`形成所有区域的比例，还将其注入山城控制器。它混合了策略与容量，不能作为甲方规定32.8%的依据。

用户已确认：默认SC采用山城30%策略，YA_B、YA_C采用一般33.3%策略。策略按显式配置选择，不从设备名称或母线名称推断。

## 决策

- `resources.contracts.WindReactivePolicy`拥有具名策略、精确比例和资料出处。一般策略使用0.333，不使用1/3；山城策略使用0.30。
- `WindReactiveCapability`表达独立的比例、绝对Q容量与MVA包络。求解器保留既有容量多边形约束，另施加绝对Q界与kP界；执行层使用相同声明边界及容量圆。零比例表示不允许调Q，不能被默认值替换。
- 允许`studies.contracts → resources.contracts`，仅导入轻量策略契约，依赖图无环。登记于`docs/architecture/modules.toml`；不引入领域I/O或求解器依赖。
- 统一台账升级为`oilfield-unified-dataset-v2`，区域配方升级为`shancheng-simulation-v2`，数据revision为`2026-09-20-v2`。新配方必须明确策略与风机容量来源；SC/YA配置由台账决定。新输入不允许静默落回旧比例。
- 保留原模拟MW/MVA/绝对Q容量，并标明来自v1模拟假设，未经现场铭牌确认；不人为放大设备容量。绝对Q原来按0.328乘额定MW生成，但新版不再把它折算为全时段比例。实际可调范围仍可能小于33.3%。
- 旧v1配方按原规则重建，缺少新字段的历史算例维持原容量语义。兼容分支中的0.328只用于历史回放。新包记录策略、容量与来源；解码时核对优化输入和设备能力，拒绝放宽已声明策略或不一致的设备包。
- 默认山城控制器继续采用30%；通用模拟执行器只注入输入中明确声明且校验过的策略限制，确保默认SC不会被一般33.3%覆盖。

## 替代方案与影响

全局替换0.328为0.333会覆盖山城专用边界，且仍可能被Q额定/P额定压回旧比例，故不采用。提升台账容量以追求比例满额没有现场依据，故不采用。策略和容量分离会改变新算例可行域和调度结果；旧结果不重写、不重新标注为v2。

两个优化器的容量多边形近似仍可能比执行层容量圆更保守，此次不改变数值近似方法。仿真权限、设备可用性、命令生命周期、光伏纯有功与储能无功关闭规则保持原语义。

## 验证

手算边界覆盖P=0、正负Q、0.333与0.30、零授权、绝对容量主导及MVA主导。两个真实求解器采用会触及边界的算例，证明比例与绝对Q限制分别生效。跨入口测试覆盖台账、Web/CLI算例、设备包、专项配方、历史v1读取以及策略篡改拒绝；既有设备控制与分钟执行回归验证执行范围。

模式快照和Web只读台账投影由既有生成器更新。架构检查改读版本控制中的`docs/architecture/modules.toml`，避免使用本地残留的`docs3/architecture/modules.toml`旧副本；将已存在的project_dataset兼容桥接登记同步到权威登记表。
