# ADR 0032：单微网复用质量优先策略及质量展示

状态：采纳。日期：2026-09-27。负责人：优化调度维护负责人、前端维护负责人。

## 背景与决策

用户明确要求单微网删除手动求解时限，采用与集群相同的质量优先后台策略。本决策扩展 ADR 0031 的适用场景，保持其预算、精度和停止条件。

网页单微网普通任务与事件分支显式发送 `quality-first-v1`，不继承旧草稿或基线的手动时限。服务装配将策略传给无储能基准和优化方案，复用 dispatch 的公开契约及既有 AC 数值桥；不复制重试规则。两类方案分别保存质量证据、产生质量校核，精度不足保留可用结果和 unknown，不记为整体通过。单微网不运行 ADMM。

将原集群质量明细提取为 `features/computation-quality`，由仪表盘和集群通过公开 `index.ts` 使用，依赖边登记在 modules.toml。展示只读生成契约，不判定求解质量。单微网只展示优化证据，集群仍展示协调和执行阶段证据。

## 备选与影响

只隐藏控件但沿用固定时限无法满足用户确认的质量策略；另建单微网策略会重复预算和失败规则，因此均不采用。困难模型可能耗时增加，但保护上限有限。时段数、区域、储能与事件输入保持原语义；历史未携带策略的 API/CLI 请求继续按手动预算运行，历史结果不补造质量证据。通信故障和群控场景保持原有预算入口。

## 验证

单微网多区域、时段与储能组合实算对照；预算耗尽时保留结果但不通过；旧请求和结果兼容；前端普通与事件请求、摘要、质量明细和集群回归；架构检查、类型检查及安装包冒烟。模型边界见 [计算质量说明](../../modeling/Computation_Quality.md)。
