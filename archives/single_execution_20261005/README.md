# 单微电网统一前的回归基线

`source.zip` 冻结改造前工作区的源码、测试、配置和打包描述，包含当时尚未提交的普通执行和条件保证实现。它不是仅按 Git HEAD 导出的快照，也不作为正式运行包的一部分导入。

`manifest.json` 记录每个文件及压缩包的 SHA-256。`environment.txt` 保存原验证环境的依赖版本。完整工作区和交底书修改前原件另保存在本地 `artifacts/single-unification-20261005/baseline`。

使用 `tools/replay_single_baseline.py` 在隔离临时目录重放。历史测试通过不表示旧实现已获得新版保证；旧版全天默认算例曾在第 975 分钟因规划不可行停止，96 时段算例完成全天但未满足所有有功响应期限。原有低负荷反送电回归用例及两时段 CLI 用例也存在已记录失败。

正式实现与迁移规则见 ADR 0046。此归档应保持不变；新的验证结果放在独立输出目录。
